# Nova X Pro - Trang giới thiệu sản phẩm bằng Bootstrap 5

Dự án thực hành thiết kế landing page giới thiệu smartphone bằng Bootstrap 5.3.3, Font Awesome 6.5.2, CSS và JavaScript thuần.

## Chạy dự án

1. Giải nén dự án.
2. Mở `index.html` bằng trình duyệt. Không cần cài Node.js hoặc chạy máy chủ.
3. Cần Internet để tải Bootstrap và Font Awesome từ CDN.

## Nội dung thực hành

- Bootstrap Navbar và Grid System responsive.
- Flexbox với `d-flex`, `justify-content-*`, `align-items-*`.
- Utility classes cho margin, padding, spacing và display.
- Ví dụ `display: contents` trong `.spec-group` để các thẻ thông số tham gia trực tiếp vào CSS Grid.
- Font Awesome icons.
- CSS tùy chỉnh ở mức tối thiểu để tạo nhận diện trực quan và điều chỉnh trên mobile.
- JavaScript tương tác: chọn màu, chọn dung lượng, cập nhật giá minh họa và thông báo xác nhận.

## Lưu ý

Nova X Pro là thương hiệu/sản phẩm giả lập phục vụ bài tập. Giá và thông số trong trang chỉ mang tính minh họa; nút mua không tạo đơn hàng thực tế. Hình điện thoại là SVG tự tạo nằm trong thư mục `assets`.
